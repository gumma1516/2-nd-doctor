# Self-hosted Geist

Geist Sans and Geist Mono Latin variable WOFF2 files were copied unmodified from
the installed Next.js 16.3.8 package's `dist/next-devtools/server/font` directory.
They are loaded through `next/font/local`; rendering and production builds do not
contact an external font service. Keep OFL.txt alongside the fonts.

Font project: https://github.com/vercel/geist-font
Design and licensing: https://vercel.com/font
